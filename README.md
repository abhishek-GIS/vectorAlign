# vectorAlign

**Advanced spatial adjustment and alignment for vector layers.**

vectorAlign (formerly Spatial Adjustment Pro) is a QGIS plugin for aligning, shifting, scaling, rotating and rubber-sheeting vector layers using displacement (control) links — featuring live snapping, on-canvas preview, safe export, and feature-to-feature attribute transfer. Fully compatible with QGIS 3 (Qt5) and QGIS 4 (Qt6).

### ✨ Features
* **Transformation methods:** Similarity, Affine, Projective, Thin-Plate Spline, and Polynomial (order 2 & 3).
* **Smart Align:** Auto-centers and scales data based on its core features.
* **Live preview:** See the result on the canvas before committing.
* **Safe export:** Modify in place, or write to a new layer with a custom CRS.
* **Attribute transfer:** Copy attributes from one layer's features to another using spatial matching.

### 🚀 Usage
1. Click the **vectorAlign** toolbar icon.
2. Add the layer(s) you want to adjust.
3. Choose a transformation method (Affine, Similarity, etc).
4. Run **Smart Align**, or **Capture Links** by clicking matching source→target locations on the canvas.
5. Preview, then execute!
